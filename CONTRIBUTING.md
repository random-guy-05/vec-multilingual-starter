# Contributing

Corrections from native speakers and Challenge participants are welcome.

## Translation rules

1. Do not change command names, board IDs, AnnData keys, paths, URLs or numeric board limits while translating.
2. Keep `.X`, `var_names`, `obsm["spatial_3D"]`, task IDs and filenames in code formatting.
3. Translate the explanation, not code tokens.
4. If an official rule changes, update [docs/sources.md](docs/sources.md) and the English guide first, then synchronize every translation.
5. Do not add unverified claims about hidden data, hidden test scores or organiser decisions.

## Before opening a PR

Check that the guide still contains these sections:

- Register and download
- Five boards
- Install
- Baseline
- Validate
- Pseudo split / local score
- Upload
- Final phase
- Agent evidence
- Common mistakes

Please identify whether a translation was native-reviewed, machine-assisted, or community-reviewed in the PR description.
