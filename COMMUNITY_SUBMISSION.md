# Community Contribution submission text

## Title

VEC Multilingual Starter — zero-to-first-submission guides in nine languages

## Short description

VEC Multilingual Starter is a synchronized multilingual onboarding resource for the Virtual Embryo Challenge. It provides complete zero-to-first-submission walkthroughs in English, Spanish, Simplified Chinese, Hindi, Portuguese, French, Arabic, Japanese and Korean. Every guide covers registration, downloading the released data, the five current validation boards and their exact gene/cell bounds, building and validating a baseline submission, local pseudo-split scoring, uploading, final-phase changes, Agent Team evidence requirements and common first-submission mistakes. Technical facts are centralized in one source-of-truth document with official URLs and a verification date so translations can be kept synchronized as the Challenge changes. The non-English guides are machine-assisted; their technical literals and commands are checked automatically across all nine guides, and the repository explicitly invites native-speaker corrections.

## Contribution / community value

The existing vec-community-kit already provides an excellent English/Chinese tutorial. This contribution extends that onboarding path to seven additional major languages while also providing one multilingual landing page, a shared glossary/source document, and a translation-maintenance policy. The goal is reach rather than new modelling machinery: students and first-time entrants can follow the same technical workflow without needing to read a long English-only rules/evaluation stack. The Challenge award page explicitly states that translations count and specifically notes that a Chinese tutorial is a valid community contribution.
